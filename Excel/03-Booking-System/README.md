# Excel Booking & Capacity Tracking System

## Project focus
An internal Excel booking and tracking system for a service business that needs to manage reservations, dates, capacity, payments, and daily operations in one workbook.

## Features
- Customer / owner details
- Service type and booking dates
- Multiple resources or animals per booking
- Notes and booking status
- Upcoming arrivals and departures
- Date and service filters
- Capacity tracking
- Deposits and payments
- Basic revenue summary
- Daily operational sheets

## Business value
The goal is to replace scattered manual tracking with one structured workbook that is easy for staff to update and review.

## Workflow
1. Confirm the business rules and required fields.
2. Design the booking table and reference lists.
3. Add formulas, validation, and status logic.
4. Build capacity and date checks.
5. Add summary views for upcoming bookings and revenue.
6. Test with sample bookings and edge cases.

## Tools
Microsoft Excel · Data Validation · XLOOKUP · SUMIFS / COUNTIFS · Conditional Formatting · Tables · Filters
