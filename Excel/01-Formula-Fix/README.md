# Excel Formula Fix & Error Troubleshooting

## Problem
Existing Excel workbooks can return incorrect results because of broken references, inconsistent formulas, lookup errors, or calculation logic issues.

## What I fix
- `#REF!`, `#VALUE!`, `#N/A` and similar errors
- XLOOKUP / VLOOKUP issues
- SUMIFS / COUNTIFS / IF / IFERROR logic
- Broken or shifted references
- Inconsistent formulas across rows or periods
- Reconciliation differences
- Incorrect calculations based on business rules

## Process
1. Review the workbook and reproduce the issue.
2. Confirm the expected result.
3. Trace formulas and dependencies.
4. Identify the root cause.
5. Fix the formula or spreadsheet logic.
6. Validate the corrected result.
7. Explain what was changed.

## Deliverables
- Corrected Excel workbook
- Fixed formulas and references
- Validation or reconciliation checks where relevant
- Short root-cause explanation

## Tools
Microsoft Excel · XLOOKUP · SUMIFS · IF / IFERROR · Data Validation · Reconciliation
