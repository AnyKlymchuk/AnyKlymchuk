# Excel Model Reconciliation & Automation

## Project focus
Technical troubleshooting and automation of an existing Excel model using the client's business rules and expected outputs.

## What I can do
- Trace formulas and workbook dependencies
- Find technical and calculation errors
- Reconcile linked sheets and outputs
- Add control checks
- Automate repetitive calculations
- Improve workbook structure and maintainability
- Preserve the existing model wherever possible

## Example use case
A 3-statement model contains P&L, Balance Sheet and Cash Flow outputs. The task is not to provide financial advice, but to make the spreadsheet logic technically correct and consistent.

## Workflow
1. Review the workbook and business rules.
2. Identify broken formulas, links, or inconsistencies.
3. Reconcile P&L, Balance Sheet, and Cash Flow outputs.
4. Add checks for key totals and linked calculations.
5. Simplify repetitive logic where useful.
6. Validate the final workbook.

## Deliverables
- Corrected Excel workbook
- Reconciliation checks
- Cleaner formulas and structure
- Short explanation of the root cause and changes

## Skills
Microsoft Excel · Spreadsheet Automation · Formula Troubleshooting · Data Validation · Reconciliation

> This service is technical spreadsheet troubleshooting, not financial advisory.
