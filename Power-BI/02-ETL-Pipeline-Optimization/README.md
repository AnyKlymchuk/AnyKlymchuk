# Power BI & ETL Pipeline Optimization

## Project focus
Troubleshooting and automation across the reporting pipeline: source files, Python ETL, SQL/PostgreSQL, validation, logging, and Power BI refresh.

## What I can help with
- Python ETL troubleshooting
- SQL/PostgreSQL transformations
- CSV / Excel / database ingestion
- Data validation and reconciliation
- Duplicate and missing-data checks
- Rolling-period loads
- ETL logging and error tracking
- Power BI refresh and query optimization
- Data model consistency checks

## Workflow
1. Review the pipeline and reproduce the issue.
2. Identify whether the root cause is in the source, transformation, database, Power Query, or model.
3. Fix the failing step.
4. Add validation or logging where useful.
5. Reconcile row counts and key totals.
6. Test the full flow through to Power BI.
7. Document the change.

## Deliverables
- Corrected pipeline logic
- Validation/reconciliation checks
- Improved reliability and easier troubleshooting
- Short technical explanation of the root cause and fix
