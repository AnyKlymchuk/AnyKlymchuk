# Power BI Troubleshooting

## What I solve
I troubleshoot existing Power BI reports and data models, identify the root cause of errors, and implement the smallest reliable fix without unnecessarily rebuilding the solution.

### Typical issues
- DAX formula errors and incorrect calculations
- Power Query / M errors
- Refresh failures
- Broken or changed data source connections
- PostgreSQL, Excel, CSV, SharePoint and database connection issues
- Relationship and data model problems
- Missing or duplicated data
- Filter context issues
- Data type and schema errors

## My process
1. Reproduce the issue.
2. Review the error message, report logic, DAX, Power Query and model.
3. Identify the root cause.
4. Fix the measure, query, relationship, source connection or refresh logic.
5. Test the affected calculations and refresh.
6. Validate the final result.
7. Deliver a short explanation of what caused the problem and what changed.

## Deliverables
- Corrected Power BI solution
- Fixed DAX / Power Query / connection issue
- Validated report result
- Short root-cause explanation
