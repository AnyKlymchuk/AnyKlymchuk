## How I work

1. Review the file, report, error message, or pipeline.
2. Confirm the expected business result.
3. Trace formulas, queries, relationships, dependencies, or source connections.
4. Identify the root cause.
5. Implement the smallest reliable fix.
6. Reconcile and validate the result.
7. Deliver the corrected solution with a short explanation of what changed.

> Portfolio examples use demonstration or anonymized data. Client credentials and confidential data are never included in public repositories.
