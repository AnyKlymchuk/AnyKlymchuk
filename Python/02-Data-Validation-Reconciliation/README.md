# Data Validation & Reconciliation

## Project focus
Compare source and target data, identify mismatches, and create checks that make data issues visible before they reach reporting.

## Typical checks
- Row counts by file, date, or business key
- Duplicate detection
- Missing records
- Null and invalid values
- Sum reconciliation
- Source vs target comparison
- Date range validation
- Status and exception reporting

## Workflow
1. Define the expected business rules.
2. Compare source and target datasets.
3. Identify mismatches and exceptions.
4. Produce a reconciliation summary.
5. Add repeatable validation checks.

## Tools
Python · pandas · SQL · PostgreSQL · Data Validation · Reconciliation
